# Dallas Towers — The Data Moat

*The strategic objective is not to own the phrase "Dallas condos." It is to make
Dallas Towers the place where a serious buyer understands the building itself
better than they can from any listing portal.*

## The hierarchy

```
Building census                 89 files: every file is a permanent entity
      ↓
Verified identity data          name · address · district · era · floors · units
      ↓
HOA / rules / documents         dues with dates · leasing & pet rules · what to request
      ↓
Floor plans / stacks            plan records · stacks · orientations (rights-clean)
      ↓
Public-record economics         certified-roll values · homestead proxy · transfer tempo
      ↓
Historical observations         append-only: dues over time, roll over years
      ↓
Building comparisons            tower-to-tower on verified dimensions only
      ↓
Buyer decision intelligence     "what to verify before you offer" per building
```

## The principle: depth compounds

Every verified field improves the same permanent entity. A listing portal's page
dies with the listing; a building file appreciates. The moat is not URL count —
it is the accumulated, provenance-backed record that competitors would need years
of verification work to replicate.

## Rules that protect the moat

1. **No invented data — absolute.** A short verified file beats a complete-looking
   fictional one. Unknown stays unknown, and says so gracefully.
2. **Assessed is never sale.** Texas is a non-disclosure state. Assessed values,
   $/sf and dispersion are certified-roll facts; transfer records are dates and
   instruments, never prices. The validator enforces the vocabulary.
3. **Proxies are labeled as proxies.** Homestead-exemption share is an
   owner-occupancy *proxy*, stated as such with methodology.
4. **History is append-only and starts when observation starts.** No reconstructed
   backfill without archived provenance.
5. **Publish depth, not breadth.** New building pages must clear the minimum-file
   threshold (schema §verification); enrichment of existing files outranks new URLs.
6. **Rights-clean media only.** No copyrighted plan artwork, no stock photos posing
   as the tower, schematics labeled "not to scale" unless they are.

## Operating loop

verify another valuable building field → improve the permanent entity →
record provenance → measure search/lead response → repeat.
